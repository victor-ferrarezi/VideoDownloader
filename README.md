# VideoDownloader

Aplicativo desenvolvido em Java para estudo e portfólio.

## Objetivo

O VideoDownloader terá como objetivo receber uma URL de uma plataforma suportada, obter informações do vídeo e realizar o download de conteúdo que o usuário tenha autorização para baixar.

## Tecnologias

- Java 17
- Maven
- Git
- GitHub
- yt-dlp

## Status

🚧 Em desenvolvimento.

Atualmente o projeto possui:

- Projeto Maven
- Menu inicial
- Entrada de URL
- Validação inicial de URL do YouTube

## Uso responsável

O aplicativo deve ser utilizado somente para conteúdos que o usuário tenha autorização ou direito de baixar, respeitando os termos das plataformas e os direitos autorais.
